1 Exam habits that save marks

  • Units first. Tools › Options › Document Properties › Units: MMGS, and the decimal places the question asks for (usually 2).
  • Save each stage as a new file (Part_S1, Part_S2, Part_S3). A later mistake never costs you an earlier answer.
  • Read the whole question before you sketch: origin position, material, units and which sizes change in later stages.
  • Rebuild before you read results: Ctrl+Q forces a full rebuild.
  • Far off the answer choices? Answers are usually accepted within about 1%, so a big miss is a modelling error (a cut through all, the wrong material, the wrong origin), not rounding.

2 Mass properties

  • Evaluate › Mass Properties. Set the material first: right-click Material in the tree › Edit Material.
  • Mass = volume × density. 1 g/cm³ = 1000 kg/m³ = 0.001 g/mm³.
  • The centre of mass is measured from the part origin, unless you pick a coordinate system under "Report coordinate values relative to".
  • Drawing origin not at your part origin? Insert › Reference Geometry › Coordinate System at that point, then report relative to it.
  • Mass Properties shows the active configuration only.

3 Equations and global variables

  • Tools › Equations. Names go in double quotes.
  • Global variable: "Width" = 80
  • Dimension: "D1@Sketch1" = "Width" / 2 - 5
  • Choice: IIF("Width" > 60, 6, 4)
  • Whole number: int(("L" - 2 * "E") / 40) + 1
  • A dimension driven by an equation shows Σ. Change the variable, not the dimension.
  • Rename key dimensions (e.g. Width@Sketch1) so equations stay readable.
  • Order matters: × and ÷ come before + and −. Use brackets.

4 Configurations and design tables

  • Insert › Tables › Design Table (an Excel sheet inside the part).
  • First column = configuration names. Header row = what each column controls.

  • Editing a value: This configuration changes one, All configurations changes every one.
  • Derived configurations inherit everything they don't change from their parent.

  • Assembly centre of mass: from the assembly origin, or a coordinate system you choose.

6 Interference and collisions

  • Evaluate › Interference Detection checks the assembly where it is now, and lists each clash with its volume.
  • Treat coincidence as interference also lists faces that only touch.
  • Move Component › Collision Detection › Stop at collision: dragging stops when parts touch. Physical Dynamics pushes them instead.
  • Clearance Verification lists gaps smaller than a value you set.
  • Pin Ø d in hole Ø D: clearance = D − d. If d > D, the overlap volume is π/4 × (d² − D²) × length.
  • Tools › Evaluate › Measure for distances and angles between any two entities.

7 Sheet metal

Bend allowanceBA = θ × π/180 × (R + K·T)
K-factorK = t ÷ T (usually 0.3–0.5)
Outside setbackOSSB = tan(θ/2) × (R + T)
Bend deductionBD = 2 × OSSB − BA
Flat length (outside sizes)L₁ + L₂ − BD

R = inside radius, T = thickness, θ = bend angle, t = distance from the inside face to the neutral axis.

8 Simulation hand checks

Axial stressσ = F ÷ A (N/mm² = MPa)
Factor of safetyFoS = yield ÷ max von Mises
Rectangle, b × hI = b·h³ ÷ 12
Cantilever, end loadδ = F·L³ ÷ (3·E·I)
Cantilever, bendingσ = 6·F·L ÷ (b·h²)

E: steel ≈ 210 GPa, aluminium ≈ 69 GPa. If the simulation and the hand check differ a lot, check units, fixtures and the load direction.
